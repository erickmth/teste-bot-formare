# 🤖 Bot de WhatsApp para Sistema de Reservas

Um bot automatizado para WhatsApp que gerencia reservas de quartos e espaços através de menu interativo.

## 📋 Funcionalidades

- ✅ **Fazer reserva** - Cria nova reserva com ID único
- 📊 **Consultar reservas** - Lista todas as reservas ativas do usuário
- ❌ **Cancelar reserva** - Remove reservas existentes
- 👨‍💼 **Suporte ao cliente** - Fornece informações de contato
- 💾 **Armazenamento local** - Salva dados em arquivo JSON

## 🚀 Como Usar

### Pré-requisitos
- Node.js instalado
- WhatsApp Business ou conta pessoal no celular

### Instalação


- npm install

- npm start
- npm install whatsapp-web.js qrcode-terminal fs path
